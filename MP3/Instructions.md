Write a _BNF grammar_ for the language of palindromes. In evaluating the string, spaces should not be considered. Kindly note that the grammar should be case sensitive, that is, big C is considered as a different character from small c.

**IMPORTANT:** Define and formulate your BNF grammar that accepts a palindrome. Comment in your source code the BNF grammar you have defined. Make sure that your implementation does not use predefined functions to determine whether a string is a palindrome or not. Source code will be checked as well. _DO NOT USE PREDEFINED FUNCTIONS/METHODS FOR DETERMINING IF A STRING IS A PALINDROME OR NOT_.

**Examples...**
Palindrome: pop, pop a pop, a but tuba, racecar
Not a palindrome: hey, joe, the quick brown fox, hmph, RaCeCar
